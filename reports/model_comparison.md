## Note on accuracy

99%+ accuracy is unusually high for a real-world text classification task, so it's worth explaining rather than just reporting. The Bitext dataset is synthetically generated by an LLM with fairly consistent, templated phrasing per intent, which makes the intents more linearly separable than genuine customer messages would be (typos, slang, multi-intent messages, ambiguous phrasing). This number should be read as "the model has fully learned this dataset's patterns," not as an estimate of real-world production accuracy.

Two design choices in this project are aimed at the gap between this dataset and real messages rather than at inflating this number further:
- **Character-level n-grams (3–5)** instead of word-level tokens, which are more robust to misspellings (see `test_misspelled_order_tracking` in `tests/test_predictions.py`).
- **Probability calibration** (`CalibratedClassifierCV`, sigmoid, 3-fold CV), so the confidence score can be trusted enough to gate automation (AUTO vs REVIEW), rather than relying on raw accuracy as the only signal of reliability.
